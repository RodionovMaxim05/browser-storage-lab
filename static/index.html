Сравнение технологий

Технология Что хранит Срок хранения Доступ сервера
Cookies Небольшие значения Сессия или заданный срок Да, если подходят условия отправки
LocalStorage Строки До удаления Нет, напрямую не отправляется
SessionStorage Строки Сессия вкладки Нет, напрямую не отправляется
IndexedDB Структурированные данные До удаления или очистки браузером Нет, напрямую не отправляется
Cache API Request / Response До удаления или очистки браузером Нет, это браузерный кэш
Service Worker Сам по себе не является хранилищем Регистрация может сохраняться между сессиями Может обрабатывать запросы через Fetch API
